Эта папка нужна для полностью автономной работы шрифтов.
По умолчанию пакет google_fonts скачивает шрифты (Playfair Display, PT Sans) при первом
запуске с интернетом и дальше хранит их в кэше. Чтобы шрифты были и при самом первом
запуске без сети, положите сюда файлы PlayfairDisplay-*.ttf и PT_Sans-*.ttf
(см. https://pub.dev/packages/google_fonts, раздел «Bundling font files»).
