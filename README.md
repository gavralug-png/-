# Православный путь

Православная викторина для Android (Flutter, Material 3). Работает полностью без интернета,
без рекламы и без регистрации.

## Запуск

Нужен Flutter 3.22 или новее (Dart 3.4+) и Android SDK.

В этом архиве лежит исходный код приложения (`lib/`, `test/`, `assets/`, `pubspec.yaml`).
Папку `android/` создаёт сам Flutter:

```bash
# 1. Создайте каркас Android-проекта
flutter create --project-name pravoslavny_put --org ru.pravoslavny --platforms android pravoslavny_put

# 2. Скопируйте поверх него файлы из этого архива:
#    lib/, test/, assets/, pubspec.yaml, analysis_options.yaml (с заменой существующих)

cd pravoslavny_put
flutter pub get
flutter analyze        # проверка кода
flutter test           # проверка банка вопросов и логики «Вопроса дня»
flutter run            # запуск на устройстве / эмуляторе
```

Название под иконкой: в `android/app/src/main/AndroidManifest.xml` замените
`android:label="pravoslavny_put"` на `android:label="Православный путь"`.

## Сборка APK

```bash
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.

## Структура

```
lib/
  main.dart                  точка входа, провайдеры, темы, локаль
  models/                    Question, QuizCategory, Achievement, DailyRecord
  data/                      100 вопросов (5 файлов), категории, достижения
  services/                  хранение (SharedPreferences), звук, «Вопрос дня»
  providers/                 GameProvider (прогресс), SettingsProvider (настройки)
  screens/                   имя, главный, уровни, викторина, итоги, победа,
                             вопрос дня, достижения, настройки
  widgets/                   крест, орнаменты, карточки, фон, значки, переходы
  theme/                     палитра и Material 3 темы (светлая и тёмная)
```

## Как работает игра

- Пять категорий по 20 вопросов; следующая открывается после завершения предыдущей.
- 10 очков за верный ответ. Очки за конкретный вопрос начисляются один раз (при первом
  верном ответе), поэтому повтор уровня не позволяет «накручивать» счёт. Очки никогда не отнимаются.
- «Вопрос дня»: один вопрос на календарный день, 20 очков, повторная награда невозможна,
  есть история прошлых вопросов. Вопросы берутся из общего банка без повторов в течение 100 дней.
- Прогресс, очки, достижения и история сохраняются локально и переживают перезапуск.
- Звуки и фоновая музыка синтезируются в коде (внешние аудиофайлы не нужны).

## Шрифты без интернета

Пакет `google_fonts` скачивает Playfair Display и PT Sans при первом запуске с сетью и затем
кэширует. Если нужны шрифты и при самом первом запуске офлайн, положите файлы `.ttf`
в `assets/google_fonts/` (см. `README.txt` в этой папке).

## Содержание вопросов

Вопросы составлены по Священному Писанию, Символу веры, решениям Вселенских Соборов и церковному
календарю; цитаты святых не используются. Даты праздников указаны по гражданскому календарю
(юлианский календарь Русской Церкви). Перед публикацией рекомендуется показать банк вопросов
священнику или богослову: файлы `lib/data/questions_*.dart` легко править.
